# Easy Clip Git 워크플로 스킬

Easy Clip 저장소의 Git 및 GitHub 작업 규칙입니다.

## 언제 사용하나요?

- `git` 또는 `gh` 명령을 실행할 때
- GitHub 이슈, PR, 리뷰, 체크, 병합을 다룰 때
- 브랜치, 커밋, push, 이력 재작성, 브랜치 정리를 할 때

## 핵심 규칙

- 이슈를 먼저 만들고, 같은 이슈 번호를 브랜치·커밋·PR에 사용합니다.
- 커밋 메시지, PR/이슈 제목과 본문은 한국어로 작성합니다.
- 커밋과 PR 제목은 `#관련이슈/type(scope) : 메시지` 형식을 사용합니다.
- 저장소 상태를 먼저 확인하고, 요청 범위 밖의 변경은 건드리지 않습니다.
- GitHub 관련 작업을 에이전트에 위임할 때는 완료 가능한 가장 작은 모델을 사용합니다.
- commit, push, PR 생성/병합, force-push는 사용자가 명시적으로 요청한 범위에서만 수행합니다.
- 비밀값, 환경 파일, 토큰은 코드·커밋·GitHub 메타데이터에 포함하지 않습니다.

자세한 실행 절차와 허용 type/scope는 `SKILL.md`를 기준으로 합니다.
