# Easy Clip Git 워크플로 스킬

이 스킬은 Easy Clip 저장소에서 이슈 생성부터 브랜치 정리까지 Git과 GitHub 작업을 일관되고 안전하게 수행하도록 안내합니다.

다음 작업에서 사용합니다.

- GitHub 이슈 생성과 템플릿 선택
- 이슈 기반 브랜치 생성과 전환
- 커밋 메시지와 PR 제목 작성
- stage, commit, push, PR 생성 및 병합
- `dev`에서 `main`으로 배포 변경 반영
- 병합된 브랜치 정리
- 공개 브랜치의 커밋 이력 재작성 검토

커밋과 PR 제목은 `#관련이슈/type(scope) : 메시지` 형식을 사용합니다. 이 스킬은 관련 이슈, 허용 type/scope, 한국어 메타데이터, 검증 결과 기록과 force-push 같은 위험 작업의 확인 절차를 함께 관리합니다.

실제 작업 지침은 같은 폴더의 `SKILL.md`를 기준으로 합니다.
