# Free 폴더 접근 제한

#150은 Free에서 폴더 1개만 열람·편집하도록 제한한다. 다른 폴더의 기존 데이터는 보존하며 Pro 이용 기간에는 전체 접근을 허용한다. 클립 추가 저장 한도는 [클립 한도 문서](clip-plan-limits.md)를 따른다.

## 선택과 삭제·복구

- 첫 Free 접근 시 활성 폴더를 `order ASC, id ASC`로 정렬해 하나를 선택하고 워크스페이스에 저장한다. 요청한 폴더나 요청 도착 순서는 선택 기준이 아니다.
- 같은 구독 기간의 Free 이용 중에는 선택을 고정한다. 자유로운 선택 변경 API는 제공하지 않으며 Free 폴더 재정렬도 차단한다.
- 선택된 폴더를 삭제해도 다른 기존 폴더가 열리지 않는다. 선택된 폴더는 다른 잠긴 활성 폴더가 남아 있어도 복구할 수 있다. 이 예외는 원래 자료를 되찾기 위해 다른 폴더까지 삭제하게 되는 상황을 방지한다.
- 다른 기존 폴더의 복구는 차단한다. 선택 이력이 없고 활성 폴더도 없는 최초 상태에서는 한 폴더를 복구해 선택할 수 있다. Free에서 두 폴더를 함께 복구하지 못한다.
- 활성 폴더가 있으면 Free 폴더 생성을 차단한다. 선택된 폴더가 휴지통에 있으면 복구해야 한다. 그 폴더가 영구 삭제되었고 활성 폴더도 없으면 새 빈 폴더를 만들 수 있다. 이 동작은 다른 기존 폴더를 열어주지 않는다.
- 유효 Pro 재구독은 전체 잠금을 해제한다. 다음 Free 기간에는 당시 정렬을 기준으로 다시 선정한다. 중간 Pro 요청이 없더라도 구독 종료 시각이 바뀌면 새 기간으로 구분한다.

삭제 후 자동 전환도 교대 접근을 허용하므로, 우회 차단 의도에 맞춰 선택 고정을 적용했다. 폴더 이름·ID 등 관리용 메타데이터와 콘텐츠 접근은 구분한다.

## API 범위

폴더 목록은 잠긴 폴더의 관리용 메타데이터와 `isLocked`를 반환한다. 잠긴 폴더·클립의 명시적 콘텐츠 조회와 변경은 `403 PROJECT_LOCKED`로 거부한다. 다른 사용자의 항목과 존재하지 않는 항목에는 기존 `404` 처리를 유지한다.

전역·폴더별·즐겨찾기·최근 열람 목록, 제목·태그 검색 및 커서 검사는 접근 가능한 클립만 대상으로 한다. 필터는 페이지 제한 이전에 적용한다. 최종 페이지 조회는 같은 권한 상태로 검색 분기와 커서를 다시 확인한다. 접근 범위를 벗어난 커서는 `404` 또는 기존 휴지통의 빈 페이지 규약을 따른다.

클립 생성·수정·태그 연결·좋아요·열람 기록·단건/일괄/전체 삭제와 폴더 이름·태그 변경은 최종 DB 작업에서도 접근을 검사한다. 일괄 요청에 접근 불가 항목이 있으면 전체를 거부한다. 이미지 업로드 중 플랜이 만료돼도 최종 쓰기에서 잠금을 적용하며, 실패 업로드 정리는 실제 DB 참조를 확인한다.

잠긴 폴더 자체를 삭제하는 관리 작업은 허용한다. 휴지통에는 삭제 폴더의 메타데이터와 접근 폴더의 삭제 클립만 표시한다. 잠긴 활성 폴더의 삭제 클립은 응답에서 제외한다. 휴지통 전체 비우기는 숨겨진 항목도 포함하고, 소유권을 확인한 영구 삭제·기간 만료 정리는 접근 잠금과 무관하게 수행한다.

폴더 생성·복구 수 제한은 `409 PLAN_LIMIT_EXCEEDED`, Free 재정렬은 `403 FEATURE_NOT_AVAILABLE`로 반환한다. 선택된 폴더의 태그 기능은 기존대로 유지한다. Free 전체에 대한 별도 태그 유료화는 이 변경에 포함하지 않는다.

## 동시성과 배포

구독 행 잠금으로 선정·폴더 생성·복구·콘텐츠 쓰기와 결제 권한 변경을 직렬화한다. 여러 폴더·클립은 ID 순으로 잠그며, 폴더 다음 클립 순서를 지킨다. 잠금을 기다린 뒤 유효 플랜을 재검사한다. 자동갱신 플래그만으로 만료된 Pro를 인정하지 않고, 해지했어도 결제한 기간이 남아 있으면 Pro다.

`20260908080000_add_free_folder_access` 마이그레이션이 필요하다. 기존 콘텐츠는 수정·삭제하지 않으며 첫 보호 요청에서 선정한다. 선택 ID는 삭제 이력을 보존하기 위해 FK 자동 해제 대상으로 두지 않고, 실제 접근 시 워크스페이스 소속을 검증한다. 새 환경변수는 없다.

클라이언트는 잠금 표시와 업그레이드 안내, 선택 폴더 삭제 후 자동 전환되지 않는다는 안내를 적용해야 한다. 공개 이미지 URL 자체의 접근 제어는 이번 API 잠금으로 바뀌지 않는다. 이미 확보한 이미지 URL·다운로드 자료까지 회수하는 기능은 아니다.
